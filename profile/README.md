# ScrapKit

Scrap turns fragments of code into reusable systems.
Each scrap is small, intentional, and independent — built to be reused, recombined, and reshaped.
This is an ecosystem of open source building blocks for developers who prefer composition over complexity.

---

## What is ScrapKit?

ScrapKit is an open source ecosystem of modular, composable building blocks.

Instead of large, rigid systems, ScrapKit focuses on:
- small pieces of logic
- clear boundaries
- high reusability
- intentional design

Each "scrap" is designed to stand alone, but also to combine naturally with others.

Think of it as:
> a toolbox where every tool can become part of a larger machine.

---

## Philosophy

ScrapKit is built on a simple idea:

> complexity should emerge from composition, not from size.

We believe that modern software fails when:
- systems grow too large to reason about
- abstractions become opaque
- reuse becomes painful instead of natural

ScrapKit exists to invert that direction.

---

## Principles

- **Small is powerful** — every scrap should do one thing well
- **Composition over complexity**
- **Clarity before cleverness**
- **Reusability is a first-class feature**
- **No hidden behavior**
- **Explicit boundaries**
- **Independence by design**
- **Documentation is part of the code**

---

## Manifesto

We build fragments, not monoliths.

We believe software should be assembled, not inherited.

We publish our work because knowledge grows when it is shared, not when it is contained.

We design every piece as if it will be used in systems we will never see.

We prefer clarity over cleverness, and composition over complexity.

We do not chase size. We chase coherence.

---

## Why "Scrap"?

A scrap is:
- small enough to understand instantly
- meaningful enough to be reused
- flexible enough to adapt

A system built from scraps is not weaker.
It is more resilient.
